# Xerxes Pi — CM4/CM5 Carrier Board - Rev 2

## Overview
The **Xerxes Pi** is a compact, high-performance carrier board designed for the **Raspberry Pi Compute Module 4 (CM4)** and **Compute Module 5 (CM5)**. It integrates essential interfaces, intelligent power delivery, and expansion options suitable for both prototyping and embedded product deployment.

## Features

- **Dual Hirose 100-pin connectors** (0.5 mm pitch) compatible with CM4 and CM5  
- **USB-C port** for both **data and power**  
- **Gigabit Ethernet** interface with ESD protection
- **MicroSD card slot** for CM4 and CM5 Lite models  
- **M.2 M-Key connector** with onboard regulated power supply  
- **Boot-mode jumper** for eMMC variants of compute modules  
- **UART debug header** for serial console access  
- **I²C Qwiic connector** for peripheral expansion  
- **Fan header** for active cooling control  
- **External power input** connector  
- **Integrated PoE+ module** (IEEE 802.3at compliant)  
- **Indicator LEDs** for power and status monitoring
